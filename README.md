## Modernization planning

The current site remains a static HTML/CSS/jQuery website. The proposed rebuild
preserves its theme and original graphics, adds Instagram photos and a schedule
managed through Google Calendar, and leaves room for membership inquiries and merchandise.

Start with [the modernization documents](docs/README.md). These describe planned
work; React and the integrations have not been implemented or deployed.
