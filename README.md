# Knockout Fitness

A React + TypeScript modernization of the gym's existing website, preserving the
original logo, fighter artwork, yellow/black/red palette, and real gym photography.

## Run locally

Use Node 22.12+ (Node 24 recommended) and npm.

```sh
npm ci
npm run dev
```

For a production preview:

```sh
npm run build
npm run preview
```

The build prerenders all five existing `.html` pages. Upload the **contents of
`dist/`** to the confirmed GoDaddy domain document root. Serving those files does
not require a Node application. See [deployment instructions](docs/DEPLOYMENT.md)
for configuration, feed refreshes, backup, and rollback.

## Structure

| Layer               | Location                                       | Responsibility                                            |
| ------------------- | ---------------------------------------------- | --------------------------------------------------------- |
| Atoms               | `src/components/atoms/`                        | Basic brand, label, and link elements                     |
| Molecules           | `src/components/molecules/`                    | Cards, navigation, class rows, and small compositions     |
| Organisms           | `src/components/organisms/`                    | Complete gallery, program, contact, and schedule sections |
| Layout              | `src/components/layout/`                       | Shared page shell                                         |
| Pages               | `src/pages/`                                   | Compose sections for each page                            |
| Hooks / services    | `src/hooks/`, `src/services/`                  | Polling, public configuration, dates, and feed requests   |
| Content / contracts | `src/content.ts`, `src/feeds.ts`               | Gym content and validated feed shapes                     |
| Private sync worker | `scripts/providers/`, `scripts/sync-feeds.mjs` | Optional provider reads and public JSON export            |

Read [architecture conventions](docs/ARCHITECTURE.md) before extending the site.
HTML entry files are generated by `scripts/render-pages.tsx`; change React source,
not generated markup. Original imagery stays in `assets/`. The build copies it
into `public/media/` and then `dist/media/`.

## Integrations and current state

- Instagram profile: [@Knock_Out_Fitness](https://www.instagram.com/knock_out_fitness/).
  The gallery uses original local photos until valid account media is connected.
- Google Calendar: our own agenda design reads the optional worker’s public JSON
  feed. The existing weekly timetable is the fallback when that feed is unavailable.
  Set `calendarId` in public configuration only for the optional open-calendar link.
- The worker is implemented but has not been tested against the owner's accounts.
  OAuth onboarding and automatic Instagram token renewal are not implemented.
- Contact actions use existing phone, email, directions, and social destinations.
  Membership forms, payment, and merchandise remain [future work](docs/FUTURE_FEATURES.md).
- The live site has not been changed. Confirm the domain spelling, current business
  details, and timetable before publishing. The historical Saturday end-time
  discrepancy is flagged instead of silently changing it.

```sh
npm run build
npx playwright install chromium
npm run test:e2e
npm run format:check
```

TypeScript, feed-validation tests, mocked provider tests, and the production build
were verified in the development environment. Browser tests are included but
could not run there: the local browser download failed and the cloud browser
could not access the preview. Desktop/mobile visual review remains a release gate.
No live provider validation or production deployment has been performed.
